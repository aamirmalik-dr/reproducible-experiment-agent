# Changelog

All live results were produced through OpenRouter at temperature 0. Values are mean holdout gain over the fixed pipeline on held-out tasks, `(fixed - arm) / fixed`, where positive is better. Every version keeps the full history of saved outputs, trial records, scoring receipts and traces.

## 0.2.0 (2026-11-10)

Both changes in the v2 round were committed before the v2 tasks were generated:
- Planner prompt changes for both planners:
  - Unused trials are not refunded.
  - Each of the three model families should be tried before freezing.
- Run-cap reservation: the largest episode cost is reserved under the run cap.

Evaluation changes:
- A new held-out v2 family built from five new generators.
- Reports cover several live result sets.
- A per-task breakdown is written to `reports/per_task_breakdown.csv`.
- Episodes stopped at the run cap are reported as pending.
- Live configs take the adapter retry count and backoff.

Live results with `openai/gpt-4.1-mini` (10 tasks x 2 runs):

| Arm | Mean holdout gain |
|---|---|
| single call | +0.165 |
| agent | +0.150 |
| random search | +0.106 |

Live results with `anthropic/claude-sonnet-4.6` (1 run):
- The run stopped at its dollar cap after 6 of 10 tasks; 4 are pending.
- On the 6 tasks it reached: single call +0.171, agent +0.196.
- The first attempt hit HTTP 429 rate limits. It is kept under `reports/aborted/` and not counted.

Figures:
- `scripts/make_figures.py` draws every figure from saved task results, trial results and traces.
- The current set is publication-style:
  - Figure 1:
    - (a) per-task holdout gain;
    - (b) best dev gain so far by trial index;
    - (c) dev against holdout gain;
    - (d) trial-request outcomes.
  - Figure S1: paired differences.
  - Exported as SVG and as 256-colour 300 dpi PNG.
  - Task-level bootstrap and Wilson intervals.
  - Every plotted value is written to `docs/figures/figure_stats.json`.
  - The typeface, Liberation Sans, is vendored under the SIL Open Font License.
- README:
  - "Main result" section, Statistical methods paragraph and a Mermaid architecture diagram.
  - One text correction: the v1 gains on the interaction, piecewise and heteroscedastic tasks are now stated with their actual values. No result number changed.
- `tests/test_figures.py` checks that every figure is produced, stays within size limits and is reproducible.

## 0.1.0 (2026-11-09)

Components:
- A trusted split service.
- A pipeline allowlist.
- A subprocess trial runner with time and resource limits.
- An evaluator-only holdout.
- A column-leakage policy.
- Byte-identical reproduction of frozen candidates.
- agentcore 0.1.2, vendored from evidence-ledger-agent.

Tasks, arms and fixes:
- Synthetic dev and held-out task families, generated by committed code.
- Arms: fixed pipeline, random search, single call, agent.
- Fixes:
  - Tool results show the full trial spec.
  - Specs that repeat a feature column are rejected.
  - No-model baseline rows are labelled by the run that produced them.

v1 live pilot with `openai/gpt-4.1-mini` (10 tasks x 2 runs):

| Arm | Mean holdout gain |
|---|---|
| single call | +0.099 |
| agent | +0.076 |
| random search | -0.001 |

All 80 frozen candidates reproduced byte for byte.
