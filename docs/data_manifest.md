# Data manifest

No external dataset is used. Every table in `tasks/` and `evaluator/holdout/` is synthetic and fictional, generated by `scripts/make_tasks.py` and `scripts/make_tasks_v2.py` from fixed seeds (numpy `default_rng`). Re-running the script reproduces the committed files byte for byte, which a test checks.

| Family | Tasks | Generators | Rows per task |
|---|---|---|---|
| dev | dev-01 to dev-06 | linear_logit, friedman, grouped_sites | about 360 (390 with duplicates), 60/20/20 train/dev/holdout |
| heldout | ho-01 to ho-10 | interaction, piecewise, sparse_linear, imbalanced_grouped, heteroscedastic | same |
| heldout_v2 | h2-01 to h2-10 | category_slope, saturating, three_phase, counts, lot_effect (`scripts/make_tasks_v2.py`) | same |
